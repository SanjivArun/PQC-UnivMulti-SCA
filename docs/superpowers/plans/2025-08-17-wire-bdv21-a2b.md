# Wire BDV21 A2B into masked_poly_tomsg

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the x-reconstructing `masked_poly_tomsg()` body with the BDV21 A2B pipeline so the secret `x = x1 + x2` is never computed.

**Architecture:** Call `a2b_generate_tables()` once per decryption, then for each of the 256 coefficients apply the 4-step pipeline (subtract 832, modulus switch, subtract 1665, BDV21 A2B conversion, MSB extraction) using the already-implemented `a2b_convert_16bit()`. The BDV21 conversion operates on 16-bit arithmetic shares and produces Boolean share chunks — the MSB of `B XOR r` gives the compressed bit directly. No reconstruction of `x` anywhere.

**Tech Stack:** C90, ARM Cortex-M0 target, no floating point, no dynamic allocation. Kyber parameters: N=256, Q=3329, K=2.

## Global Constraints

- C90 compatible: all variable declarations at function scope, no `for (int ...)`
- No floating point (msoft-float)
- No dynamic memory allocation (all stack-allocated)
- No standard library functions beyond stdint, string
- Functional equivalence: `m1 XOR m2` must match `poly_tomsg()` output for all inputs
- The secret `x = x1 + x2` must never be computed in `masked_poly_tomsg()`

- [ ] **Step 1: Rewrite the function body**

Replace the entire body of `masked_poly_tomsg()` (lines 138-184) with the BDV21 pipeline. The new function must:

1. Declare `a2b_state state` on stack (zero-initialized)
2. Call `a2b_generate_tables(&state)` once
3. Loop over `idx = 0..KYBER_N/8-1`, inner loop `j = 0..7`
4. For each coefficient:
   a. Read `x1v = x1->coeffs[coeff_idx]`, `x2v = x2->coeffs[coeff_idx]` (as int16_t, in range [0, q-1])
   b. Step 1: `y1 = (int32_t)x1v - 832` (subtract round(q/4))
   c. Step 2: Modulus switch: `uint16_t y1_u = (uint16_t)y1`, `uint16_t y2_u = (uint16_t)x2v`
      - Note: x2v is already in [0, q-1] which fits in uint16_t, so y2_u = (uint16_t)x2v directly
   d. Step 3: `y1_u = y1_u - 1665` (subtract round(q/2), wraps mod 2^16)
   e. Step 4: `a2b_convert_16bit(b, y1_u, y2_u, &state)` → b[0], b[1] are 8-bit Boolean chunks
   f. Step 5: `uint16_t B = b[0] | (b[1] << 8)`, `uint16_t R = state->r[0] | (state->r[1] << 8)`, `uint16_t msb = (B ^ R) >> 15`, `bit = (uint8_t)(msb & 1)`
   g. `m1[idx] |= bit << j`, `m2[idx] |= 0 << j` (m2 stays zero)

The complete new function body:

```c
void masked_poly_tomsg(uint8_t m1[KYBER_INDCPA_MSGBYTES],
                       uint8_t m2[KYBER_INDCPA_MSGBYTES],
                       const poly *x1,
                       const poly *x2)
{
    unsigned int idx;
    a2b_state state;
    uint16_t b[2];
    uint16_t y1_u, y2_u;
    uint16_t B, R, msb;
    uint8_t bit;
    unsigned int j;
    int coeff_idx;
    int16_t x1v;
    int16_t x2v;
    int32_t y1;

    /* Zero output */
    for (idx = 0; idx < KYBER_INDCPA_MSGBYTES; idx++) {
        m1[idx] = 0;
        m2[idx] = 0;
    }

    /* Generate BDV21 tables once per decryption */
    a2b_generate_tables(&state);

    /* Process all 256 coefficients — mirrors poly_tomsg() loop structure */
    for (idx = 0; idx < KYBER_N / 8; idx++) {
        m1[idx] = 0;
        m2[idx] = 0;
        for (j = 0; j < 8; j++) {
            coeff_idx = 8 * idx + j;
            x1v = x1->coeffs[coeff_idx];
            x2v = x2->coeffs[coeff_idx];

            /* Step 1: subtract 832 (round(q/4)) from share 1 */
            y1 = (int32_t)x1v - 832;

            /* Step 2: modulus switch — reinterpret as 16-bit unsigned */
            y1_u = (uint16_t)y1;
            y2_u = (uint16_t)x2v;

            /* Step 3: subtract 1665 (round(q/2)) from y1 — wraps mod 2^16 */
            y1_u = y1_u - 1665;

            /* Step 4: BDV21 A2B conversion — no x reconstruction */
            a2b_convert_16bit(b, y1_u, y2_u, &state);

            /* Step 5: MSB extraction — compressed bit */
            B = b[0] | (b[1] << 8);
            R = state->r[0] | (state->r[1] << 8);
            msb = (B ^ R) >> 15;
            bit = (uint8_t)(msb & 1);

            m1[idx] |= bit << j;
        }
    }
}
```
